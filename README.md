# Bruno Ribeiro

Desenvolvedor de software com foco em engenharia backend, arquitetura de APIs e integração de inteligência artificial. Atuo na construção de plataformas, microsserviços e automação de fluxos de dados, conectando sistemas web a serviços externos e modelos de linguagem.

Trabalho na criação de aplicações do início ao fim: desde a modelagem de bancos de dados e definição de rotas até o deploy e observabilidade na nuvem. Tenho experiência no desenvolvimento de serviços utilizando Python, Node.js e Go, aplicando práticas de autenticação, controle de acesso e processamento assíncrono.

---

### Experiência Prática & Projetos

Aqui estão alguns dos sistemas que projetei e desenvolvi:

* **Plataformas de Telefonia com IA:** Orquestração de chamadas de voz integradas a agentes de inteligência artificial, com controle de sessão e processamento de eventos em tempo real.
* **Infraestrutura de Eventos (Webhooks):** Sistema para criação, validação e roteamento de webhooks com alta concorrência e persistência de dados.
* **Agentes Inteligentes e LLMs:** Integração de modelos de linguagem a aplicações corporativas para automação de tarefas, análise de logs de infraestrutura e roteamento dinâmico de contexto.
* **Aplicações e Ferramentas Web:** Desenvolvimento de sistemas web completos, interfaces em React e arquitetura de microsserviços para gestão de dados e produtos.
