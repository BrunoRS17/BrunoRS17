### 👨‍💻 Sobre mim

<img align="right" width="230" src="https://raw.githubusercontent.com/abhisheknaiidu/abhisheknaiidu/master/code.gif" alt="Developer coding animation" />

Desenvolvedor de software que gosta de transformar problemas reais em soluções com código. 🚀

Trabalho principalmente com **Python, FastAPI, Java e Spring Boot**, desenvolvendo **APIs REST, aplicações backend, integrações de sistemas e automações**.

Também tenho conhecimentos em **React, Next.js e TypeScript**, construindo interfaces e integrando aplicações web a serviços e APIs.

Exploro **Inteligência Artificial, LLMs, agentes de IA e MCP**, conectando modelos de linguagem a aplicações e processos de negócio.

Gosto de participar de todo o ciclo de desenvolvimento, da **modelagem de dados e arquitetura de software até testes, Docker, AWS e deploy**.

Sempre aprendendo, construindo e procurando maneiras melhores de resolver problemas.
